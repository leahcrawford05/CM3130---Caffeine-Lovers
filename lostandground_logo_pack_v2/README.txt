LOST & GROUND — LOGO PACK (20.11.2026)
======================================

FOLDERS
  01_Stacked          Icon above the name + "NATURAL SKINCARE" tagline
  02_Horizontal       Icon next to the name + tagline (main logo)
  03_Symbol           Sun icon on its own
  04_Without_Tagline  Stacked and horizontal logos without the tagline
                      (use these when the logo is small, e.g. website header,
                      labels under ~3 cm wide, where the tagline would be unreadable)
  05_Social_and_Web   Profile picture (1080 px, for Instagram / Facebook / Google),
                      app icon, favicon.svg, favicon-32.png, apple-touch-icon-180.png

FILE TYPES
  .svg  Vector, for web and editing (all text is outlined, no fonts needed)
  .pdf  Vector, for print and for opening in Illustrator / InDesign
  .png  1600 px on the long side, transparent background

COLOUR VERSIONS
  colour    Full colour, for light / cream backgrounds
  reversed  For dark backgrounds (cream text, full-colour sun)
  rust      One colour (rust), e.g. stamps, embossing, single-colour print
  black     One colour (black), e.g. black-and-white print

COLOURS
  Rust          #9A3F22   (name and tagline)

  Amber         #D7803A   (rays)

  Warm tan      #C8996F   (rays)
  Chestnut      #9D4A29   (rays)
  Cotton beige  #E8DCC6   (background, reversed text)
  Espresso      #2B2420   (dark background)

FONTS
  Name      Bultik (retro bubble font) — outlined in the logo files
  Tagline   Montserrat SemiBold, wide letter spacing — outlined in the logo files
  Website   Bultik for headings, Montserrat for body text

USAGE
  - Keep clear space around the logo of at least the height of the letter "L".
  - Do not stretch, recolour outside the palette, or add effects/shadows.
